# E-Commerce Analytics Project

## Project Overview

This project analyzes e-commerce data from the Olist dataset to identify sales trends, customer behavior, product performance, payment patterns, and customer satisfaction.

## Objectives

* Analyze overall sales and order performance.
* Identify top-performing product categories and sellers.
* Understand customer purchasing behavior.
* Analyze payment methods and customer review scores.
* Generate actionable insights to support business decision-making.

## Tools Used

* SQL (MySQL)
* Microsoft Excel
* Power BI
* Tableau

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist.

## Key Analysis

* Total Orders
* Total Revenue
* Average Order Value
* Customer Distribution
* Payment Type Analysis
* Product Category Performance
* Seller Performance
* Customer Review Analysis
* Order Status Analysis

## Key Insights

* Identified top-performing product categories based on sales and order volume.
* Analyzed customer reviews to understand customer satisfaction.
* Evaluated payment preferences and purchasing patterns.
* Identified trends in order and revenue performance.

## Project Files

* **SQL:** Data cleaning and analysis queries.
* **Excel:** Data cleaning and exploratory analysis.
* **Power BI:** Interactive dashboard and KPI analysis.
* **Tableau:** Data visualization dashboard.
* **Presentation:** Project summary, objectives, KPIs, challenges, and key findings.
